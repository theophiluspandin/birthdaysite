# 🎂 Happy Birthday ももちゃん — Birthday Website

An interactive, mobile-first birthday website for 勢力 桃子 (Momoko Seiriki), made by てお (Teo).
Stack: React 18 + Vite + Tailwind CSS + Framer Motion + Lucide icons + canvas-confetti.

## Customize (all in one place)

Open **`src/config.js`**:

- `photos.camera`: the slideshow inside the retro camera
- `photos.portrait`: the oval portrait in "One Last Thing"
- `polaroids`: 5 polaroids (photo, caption, the note shown when tapped)
- `playlist`: background music tracks
- `spotifyEmbedUrl`: Spotify tab (Spotify → Share → Embed → copy the `src` URL)

Folders:

```
public/
  photos/   photo1.jpg … photo5.jpg   ← Momoko's own photos (camera, polaroids, portrait)
  images/   anime decorations, exact original filenames (see ASSETS in src/config.js):
            frieren-birthday.gif, images (1).jpeg, images (2).jpeg, images.jpeg,
            7w3b9ost01761.jpg, il_fullxfull.7824593722_i3bz.jpg, unnamed.png, 1792756235918.png
  music/    track1.mp3 …
```

Everything in `public/` is deployed to Vercel as-is. The 📁 button at the top-left of the site lets you pick images/MP3s from your PC to preview them instantly (images replace the ones with the same filename; MP3s are added to the playlist). This preview is only on your device; to make it permanent, copy the files into the folders above.

Photos live in `public/photos/` and music in `public/music/`. To replace a file, drop in a new one with the same name, or add a new file and list it in `config.js`. Full `https://` URLs (Unsplash, etc.) also work.

The 3 built-in tracks are original royalty-free pieces generated by `scripts/generate-music.mjs`. The Happy Birthday melody itself is public domain. Visitors can also add their own MP3 or audio URL from the playlist button on the music card.

## Run locally on your PC

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:5173. `--host` is enabled, so phones on the same Wi-Fi can open the "Network" URL that Vite prints.

## Deploy free on Vercel

**Option A (no Git):**

```bash
npm i -g vercel
vercel --prod
```

Log in, accept the defaults (Vercel detects Vite automatically), and you'll get a URL like `https://momoko-birthday.vercel.app`.

**Option B (GitHub):** push this folder to a GitHub repo. On vercel.com, choose **Add New → Project → Import** and click **Deploy**.

## Heart-shaped QR code

```bash
npm run qr -- https://your-site.vercel.app
```

This creates `heart-qr.svg` and `heart-qr.html`. Open the `.html` in a browser, then screenshot or print it. The QR uses the highest error correction (H), and the heart pattern stays outside the code, so it scans normally. Test it with your phone camera before sharing.
